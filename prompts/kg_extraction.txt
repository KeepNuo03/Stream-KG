# 抽取规则
1. 只抽对理解本文档有实质意义的实体。丢弃 "the / and / data / paper / model / result / method" 等英文泛词，以及 "我们 / 本文 / 这个 / 如下" 等中文代词；不抽长度 ≤ 2 字符的英文单词。
2. 中英文实体都要抽，名字保留原文形式（"Transformer" 不要翻译成"变压器"）。
3. 同一实体的不同写法放进 `aliases`（如 BERT / Bert / B.E.R.T；Vaswani et al. / Ashish Vaswani）。
4. `salience` ∈ [0, 1] 评估该实体在本片段中的重要程度，**低于 0.4 的请直接舍弃**。
5. 实体总数控制在 **12 个以内**，按 salience 从高到低排序。
6. 关系必须有 `evidence` 短语（取自原文，≤ 80 字符）支撑；**没有原文证据请不要瞎编关系**。
7. 关系的 `head` 与 `tail` **必须**出现在 `entities` 列表的 `name` 字段中。
8. `confidence` ∈ [0, 1] 是你对这条关系成立的自评。
